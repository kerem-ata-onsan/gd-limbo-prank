# Geometry Dash - Limbo Key Prank

This is a fun and interactive prank application inspired by the iconic key-shuffling mechanism from the famous **Limbo** level in **Geometry Dash**. It is built using Python (Tkinter and Pillow).

⚠️ **IMPORTANT NOTE:** This program is strictly a **harmless prank** designed for entertainment purposes. It is *not* malware or ransomware. The application will close instantly and safely once the correct key is found.

## Features


- **Memory Challenge:** At the start, the correct key is highlighted in **Green** for 1.5 seconds. Once the shuffling begins, it turns red to blend in with the others.


- **Chaotic Grid Shuffling:** Instead of a simple circular motion, the keys zig-zag and switch places between grid positions dynamically.


- **Cinematic Timing:** The iconic track **NightHawk22 - Isolation** plays in the background during the shuffle. Exactly 7 seconds after the keys stop moving, the music cuts off, leaving the player in absolute silence for the final decision.


- **Fake Blue Screen (BSOD):** If the player clicks the wrong key, the mouse cursor vanishes and a convincing full-screen fake Blue Screen of Death appears. (Can be safely closed by pressing the `ESC` key).
